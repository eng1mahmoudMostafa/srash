# قائمة التحقق الأمنية

## قبل الإطلاق
- [ ] HTTPS إجباري + HSTS
- [ ] Cookies: HttpOnly + Secure + SameSite=Lax
- [ ] حماية CSRF (Django) مع نفخ التوكن للواجهة
- [ ] حماية XSS (هروب المخرجات، Content-Type nosniff)
- [ ] حماية SQL Injection (ORM عبر Django)
- [ ] Rate limiting (5/دقيقة، 20/ساعة افتراضيًا عبر Redis)
- [ ] كلمات المرور: Argon2id
- [ ] المفاتيح السرية خارج Git (`.env` مستثنى)
- [ ] صلاحيات قاعدة بيانات بأقل امتياز
- [ ] تشفير النسخ الاحتياطية
- [ ] التحقق من المدخلات وتقييد الأطوال
- [ ] ترويسات أمنية (headers)
- [ ] تحديثات التبعيات دوريًا
- [ ] 2FA للمشرفين
- [ ] سجلات تدقيق للأعمال الإدارية

## نقاط الخصوصية
- لا يُخزَّن `sender_id` أو `sender_ip` مع الرسالة.
- IP المرسل يُحوَّل إلى HMAC أحادي الاتجاه فقط لأغراض rate-limiting، باحتفاظ
  محدود، وبمفتاح يُداوَر دوريًا.
- مفتاح تشفير الرسائل لا يوضع في قاعدة البيانات ولا في Git.
- إشعارات البريد (إن وُجدت لاحقًا) لا تحوي محتوى الرسالة.

## صياغة «المجهول»
لا نكتب «لن يُكشف المستوى...». الصياغة الدقيقة:

> لا نعرض هوية المرسل للمستلم، ولا نربط الرسالة بحساب المرسل.
